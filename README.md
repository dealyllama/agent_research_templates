# Research Templates — Index

A collection of Copilot prompt templates for structured research.

## Setup Files

| File | Purpose |
|------|---------|
| [`system-instructions.md`](./system-instructions.md) | Paste into Copilot custom instructions or prepend to a session |
| [`citation-standards.md`](./citation-standards.md) | Sourcing rules, APA format guide, and academic database links |

## Templates

| File | Template | Use When |
|------|----------|----------|
| [`template-01-topic-overview.md`](./template-01-topic-overview.md) | Topic Overview | Starting fresh on any topic |
| [`template-02-deep-dive.md`](./template-02-deep-dive.md) | Deep Dive | Going narrow and deep on a subtopic |
| [`template-03-comparison.md`](./template-03-comparison.md) | Comparison Research | Evaluating two or more options |
| [`template-04-literature-synthesis.md`](./template-04-literature-synthesis.md) | Literature Synthesis | Consolidating multiple gathered sources |
| [`template-05-research-to-action.md`](./template-05-research-to-action.md) | Research-to-Action | Translating knowledge into concrete steps |
| [`template-06-fact-check.md`](./template-06-fact-check.md) | Fact Check / Validation | Verifying a specific claim |
| [`template-07-research-roadmap.md`](./template-07-research-roadmap.md) | Research Roadmap | Planning a sustained learning effort |

## Recommended Workflow

1. Load `system-instructions.md` into your Copilot session
2. Start with **Template 01** on any new topic
3. Chain into **Template 02** or **Template 07** depending on depth vs. breadth
4. Use **Template 04** once you've gathered sources
5. Close with **Template 05** to convert findings into action
